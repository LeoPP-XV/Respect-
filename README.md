# 🌭 熱狗堡點餐系統

零依賴 Node.js 點餐系統(Node 16+),多台裝置透過區網即時同步。

## 啟動
```bash
node server.js          # 預設 http://localhost:3000
PIN=123456 PORT=8080 node server.js   # 自訂密碼 / 埠號
```
其他裝置用 `http://<這台電腦的區網IP>:3000` 開啟。資料自動存於 `data/db.json`。

## 使用流程
1. 首頁只有「點餐」「系統」。客人在**點餐**選好商品 → 取得單號 → 到櫃檯。
2. **系統**(預設密碼 `103103`)內有:
   - **櫃檯**:待結帳(勾選折扣、顯示應收)→ 收款後才送去製作;待取餐叫號;可櫃檯代點、作廢。
   - **後廚**(熟食)/ **飲料**:各自只看到自己的品項,按「開始製作」→「完成」。
   - **後台**:營收/單數/折扣統計、品項銷量、訂單紀錄(可依日期、作廢、匯出 CSV)、改價、設售完、新增品項。
3. 熟食與飲料都完成後,點餐頁會顯示「可取餐」號碼,櫃檯按「已取餐」結案。單號每日從 001 重新開始。

## 折扣
櫃檯收款時勾選:追班帳+發限動折5、二獎67折(最高折40)、特獎5折(最高折50)、六獎折25、四獎飲料一瓶(折最便宜的一杯)。
抽籤與分發為獨立系統,未整合;非折價獎項(蜥蜴互動、女僕互動、美金衛生紙)請在訂單備註或現場處理。
折扣規則在 `server.js` 的 `DISCOUNTS`,可自行修改。
